# Roadhouse

Fresh Next.js starter for the new Roadhouse website rebuild.

## Current Status

- Reduced to a minimal `Hello World` page
- App Router with TypeScript
- Development server configured for port `9800`

## Requirements

- Node.js `20.9+`
- npm

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:9800](http://localhost:9800).
